# QuestArc Roadmap 🗺️

## Phase 1: The Core Engine (MVP 1) - *Current Focus*
*Goal: A functional "Play-Only" experience.*
- [ ] **Story Engine:** Implementation of the logic to track `HeroStory` objects.
- [ ] **Condition Tracking:** Support for `streak` and `simple` completion types.
- [ ] **Battle System:** Boss HP tracking and `damageModifiers` logic.
- [ ] **Persistence:** Integration with Super Productivity's sync/storage API to ensure data safety across devices.
- [ ] **Basic UI:** A SolidJS dashboard to view story text and progress.

## Phase 2: The Architect (MVP 2)
*Goal: Empower users to create.*
- [ ] **Story Editor:** A visual interface to build custom stories without touching code.
- [ ] **Template Library:** Pre-defined templates for common goals (e.g., "The Morning Routine Quest").

## Phase 3: The Library (MVP 3)
*Goal: Community sharing.*
- [ ] **Import/Export:** Ability to share Story JSONs with others.
- [ ] **Story Marketplace:** A simple way to browse and download community-created arcs.

## Phase 4: The Fellowship (MVP 4)
*Goal: Collaborative productivity.*
- [ ] **Co-op Mode:** Shared Boss HP. Multiple users contribute damage by completing their own tasks.
- [ ] **Party Stats:** See your friends' progress/story status to stay motivated together.
