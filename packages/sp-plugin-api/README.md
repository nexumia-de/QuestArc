from `packages/plugin-api/src/` of
[Super Productivity](https://github.com/johannesjo/super-productivity) at
commit `c5eb3f6c426ddebd5de3536705b9739af6bf44db` (2026-11-05).

- Why a copy: the npm package `@super-productivity/plugin-api` is at
  1.0.1 from June 2025 and lacks newer API parts QuestArc uses
  (`getDayContext`, `dataChanged`, `dayChange`).
- Update: `scripts/update-sp-plugin-api.sh <commit>` copies the files of
  another commit; record the commit here and in
  `docs/super-productivity-facts.md`.
